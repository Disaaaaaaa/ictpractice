# System implementation methods
@lo 12.2.1.7

:::cards
### Direct changeover
The old system is switched off and the new one is used **immediately**.
### Parallel running
Old and new systems **run together**; results are compared until the new system is trusted.
### Pilot implementation
The full new system is used **in one part** of the organisation first (one branch, one class, one department).
### Phased implementation
The new system replaces the old one **module by module** across the organisation.
:::

# Comparing implementation methods
@lo 12.2.1.8

:::compare
| Criterion | Direct | Parallel | Pilot | Phased |
|---|---|---|---|---|
| Risk if the new system fails | **Highest** — no fallback | **Lowest** — old system still runs | Limited to the pilot site | Limited to one module |
| Cost | **Lowest** | **Highest** — double work | Medium | Medium |
| Time to complete | Shortest | Long | Long | Longest |
| Staff workload | Training must be finished beforehand | Very high — two systems | Pilot staff train others | Gradual learning |
| Checking results | Hard — nothing to compare with | Easy — compare outputs of both systems | Real use in one place | Each module tested in use |
:::

:::compare Choosing a method from the situation
| Situation | Method |
|---|---|
| Ship-arrival tracking at a seaport — the system must never fail | **Parallel** |
| A school replaces a paper log for hobby clubs, trying it with some clubs first | **Pilot** |
| A café starts taking orders on tablets instead of at the counter | **Direct** |
| A chain of supermarkets introduces a new stock-control system in one shop | **Pilot** |
| A university introduces a new system: admissions this year, timetables next term, finance later | **Phased** |
| The old system has completely broken down | **Direct** (no alternative) |
:::

:::tip
Justify the choice with a reason linked to **risk**, **cost** or **structure**: "Parallel, **because** errors in tracking ships could be dangerous, and the old system acts as a **backup** while the new one is checked."
:::
