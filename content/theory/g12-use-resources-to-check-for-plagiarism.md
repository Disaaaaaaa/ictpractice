# Checking documents for plagiarism
@lo 12.1.3.5

:::definition Plagiarism
Presenting **someone else's words, ideas, code or images as your own**, without proper acknowledgement.
:::

:::compare Forms of plagiarism
| Form | Example |
|---|---|
| Copy-paste | Copying paragraphs from a website without quotation marks or a reference |
| Paraphrasing without credit | Changing some words but keeping the author's ideas and structure |
| Mosaic (patchwork) | Combining pieces from several sources |
| Self-plagiarism | Submitting your own earlier work again as new |
| Code plagiarism | Copying program code from a classmate or the Internet |
| AI-generated text | Submitting text written by an AI tool as your own work, when not allowed |
:::

## Anti-plagiarism resources

Services such as **Antiplagiat**, **Turnitin**, **Unicheck**, **Grammarly plagiarism checker** and free online checkers compare a document with large databases of web pages, publications and previously submitted work.

:::steps Checking a document
- Upload the file or paste the text into the service.
- The service splits the text into fragments and searches its databases for matches.
- It produces an **originality (similarity) report**: the percentage of matching text and the **sources** found, with matches highlighted.
- Review each match: properly **quoted and referenced** text is acceptable; unreferenced matches must be rewritten in your own words or cited.
- Re-check after editing.
:::

:::warning
A similarity percentage is **not a verdict** — quotations with references, common phrases and the reference list also match. The teacher looks at **what** matches, not only the number.
:::

:::tip
Avoid plagiarism: take notes in your own words, put direct quotes in quotation marks, **cite every source** (author, title, year, URL, date accessed) and keep a reference list.
:::

# Copyright protection rules
@lo 12.1.3.6

:::compare Main rules
| Rule | Meaning |
|---|---|
| Copyright is automatic | A work is protected from the moment it is created; registration is not required |
| The author owns the rights | Only the copyright holder may copy, distribute, adapt, perform or sell the work, or give permission |
| Duration | Rights last for a long time — in Kazakhstan, during the author's life plus **70 years** |
| Licences | Others may use a work only under the terms of a licence (EULA, Creative Commons, GPL) |
| Moral rights | The author's right to be named and to protect the work from distortion |
| Exceptions (fair use) | Limited quotation for study, criticism, news — **with the source cited** |
| Software | Programs are protected like literary works; installing a copy on more computers than the licence allows is illegal |
:::

:::compare Creative Commons licence elements
| Symbol | Meaning |
|---|---|
| BY | Credit the author |
| SA | Share alike — derivatives under the same licence |
| NC | Non-commercial use only |
| ND | No derivatives — no changes allowed |
:::
