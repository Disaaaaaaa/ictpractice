# Plagiarism
@lo 12.1.3.5

When students write documentation for a project — a report, a user guide, a technical description — they use many sources: web pages, books, other people's code. Using sources is normal and good; **hiding** that you used them is **plagiarism**.

:::definition Plagiarism
**Presenting another person's work, words, ideas, images or code as your own**, without clearly **acknowledging the source**. It is a form of **academic dishonesty** and can also break **copyright** law.
:::

:::definition Source and citation
A **source** is any work you take information from (book, article, web page, video, program). A **citation (reference)** tells the reader **who** created the source, **when**, and **where** to find it.
:::

:::definition Academic integrity
Doing your work **honestly**: your own words and ideas, with **every source acknowledged**, and following the rules of the task (e.g. whether AI tools or help from others are allowed).
:::

:::compare Forms of plagiarism
| Form | What happens | Example |
|---|---|---|
| **Direct (copy-paste)** | Text is copied **word for word** without quotation marks or a reference | A paragraph from Wikipedia pasted into an essay |
| **Mosaic / patchwriting** | Phrases from several sources are **mixed** together with a few words changed | Sentences from three websites stitched together |
| **Paraphrasing without citation** | Someone else's **idea** is rewritten in new words, but the source is **not given** | An article's argument retold with no reference |
| **Translation plagiarism** | A text in another language is **translated** and presented as original | An English article translated into Kazakh |
| **Self-plagiarism** | Re-using **your own earlier work** without permission or acknowledgement | Last year's project submitted for a new task |
| **Code plagiarism** | Copying program code and only changing **variable names / comments** | A classmate's Python game with renamed variables |
| **Ghost-writing / AI text** | Work written by **another person** or an **AI tool** submitted as your own, when this is not allowed | An essay generated by a chatbot |
| **Incorrect citation** | A **wrong or incomplete** source, so the reader cannot find the original | "Source: Internet" |
:::

:::cards
### Why plagiarism is a problem
- It is **dishonest** — the work does not show the student's own knowledge.
- It is **unfair** to the original author and to other students.
- The student **does not learn** the skills the task was designed to develop.
- It can **break copyright** — the author's rights are ignored.
### Consequences
- At school: **zero marks**, the work must be redone, a note to parents.
- In exams and competitions: **disqualification**.
- At university: a failed course or **expulsion**; degrees can be withdrawn.
- At work: **loss of reputation**, dismissal, **legal action** for copyright infringement.
### Why people plagiarise
- Lack of time / poor planning.
- Not knowing how to **cite** or **paraphrase** correctly.
- Thinking that information on the Internet is **free to use**.
- Pressure to get high marks.
:::

:::warning Common mistakes
- "I changed some words, so it is mine" — it is still **patchwriting / plagiarism** without a citation.
- "It was on the Internet, so anyone can use it" — web content is **protected by copyright** too.
- Forgetting that **ideas, images, tables and code** can be plagiarised, not only text.
- Thinking that re-using your **own** old work is always fine — without permission it is **self-plagiarism**.
:::

# How anti-plagiarism resources work
@lo 12.1.3.5

:::definition Anti-plagiarism resource
A program or online service that **compares a document with a very large database of texts** — web pages, books, journals and previously submitted student work — and produces a **similarity report** showing **which parts match other sources** and **how much** of the document matches.
:::

:::definition Similarity score (similarity index)
The **percentage of the document's text that matches** text in the checker's databases. **Originality** = 100 % − similarity. It measures **matching text**, not plagiarism.
:::

:::steps How a document is checked
- The user (or teacher) **uploads** the document (DOCX, PDF, TXT) or pastes the text.
- The system breaks the text into **fragments** (overlapping sequences of words, "shingles") and creates a **digital fingerprint (hash)** of each.
- The fingerprints are **compared** with its databases: the Internet, academic publications, its **archive of submitted papers**.
- **Matching fragments are highlighted**, and each match is linked to its **source**.
- A **similarity (originality) score** in % is calculated, and a **report** is produced for the user to **interpret**.
:::

:::cards
### Limitations of anti-plagiarism software
- Cannot detect copying from **sources not in its database** (printed books, private documents).
- Can be fooled by heavy **paraphrasing**, synonym-replacing tools or **translation**.
- Does not check **images, diagrams** or **ideas** well.
- **False positives** — common phrases, names, standard definitions, the reference list.
- Uploaded work may be **stored** by the service — privacy of the student's own work.
- A human must always **interpret** the report.
### What the checker cannot decide
- Whether a match is **properly quoted and cited**.
- Whether the use is **allowed** by the task rules.
- Whether the student **understood** the work.
:::

# Checking a document and reading the report
@lo 12.1.3.5

:::steps Checking your own document before submitting
- Finish the **final draft**, with all quotations in **quotation marks** and a full **reference list**.
- Upload it to the school's checker (or a free one) and wait for the **report**.
- Look at the **overall score**, then at **every highlighted passage** and its source.
- Use the filters to **exclude quotations and the bibliography** — see what is left.
- Fix every problem: add quotation marks and a reference to a quotation; **cite** a paraphrase; **rewrite** text that is too close to the source.
- **Check again** and keep the final report.
:::

:::example Worked example — Aigerim's project report
*Aigerim checks her 12-page project report with the school's checker. The report shows **25 %** similarity: 12 % from a Wikipedia article, 9 % from a student paper submitted last year, 4 % from her textbook.*

1. **Wikipedia, 12 %** — the passage is a definition she copied **without quotation marks**. She either puts it in **quotation marks with a reference** or **paraphrases** it in her own words **and cites** the article.
2. **Student paper, 9 %** — she remembers using her older brother's report. This is **plagiarism of another student's work**: she must **rewrite** the section herself.
3. **Textbook, 4 %** — a short quotation **already in quotation marks** and in the reference list. This is **acceptable**; the filter "exclude quotes" removes it from the score.
4. After the changes and a **second check** the similarity is **6 %**, made of common technical phrases and the reference list.
:::

:::cards
### Interpreting the score correctly
- A similarity score is **not** a plagiarism score — it only shows **matching text**.
- Correctly **quoted and referenced** passages, the **bibliography**, common phrases and technical terms also produce matches.
- Most checkers can **exclude quotes and the reference list** from the score.
- A **high score with no citations** needs investigation; a **low score** can still hide paraphrased or translated plagiarism.
- Many schools set a **threshold** (e.g. above 20–30 % is checked in detail), but every match is judged by a person.
### Ways of checking without a dedicated service
- Search a suspicious sentence **in quotation marks** in a search engine.
- Use **reverse image search** to find the source of a picture.
- Compare two programs with a **code-similarity tool** (MOSS, JPlag).
- Compare the **style** of a passage with the student's other work.
:::

:::warning Common mistakes
- Treating the similarity % as **proof** of plagiarism, or 0 % as proof of originality.
- Using a synonym-replacer to "beat" the checker — the work is still plagiarised and often becomes unreadable.
- Checking only the **number** and never opening the highlighted passages.
- Uploading a confidential document to a free checker without reading its **privacy terms**.
:::

Presenting someone else's work / words / ideas as your own (1) without acknowledging / citing the source (1).

**Q: Describe how an anti-plagiarism resource checks a document. [3]**
The text is split into fragments / fingerprints (1); these are **compared with a large database** of web pages, publications and submitted work (1); **matching fragments are highlighted** with their sources and a **similarity percentage / report** is produced (1).

Matches may be **correctly quoted and cited** passages, the **reference list** or common phrases (1); the teacher must look at **which parts** match and whether they are acknowledged (1).

Any two: cannot find sources not in its database (1); can be fooled by heavy paraphrasing / translation (1); false positives from common phrases; does not check images / ideas well.

MOSS / JPlag (1).

# Avoiding plagiarism
@lo 12.1.3.5 12.1.3.6

:::definition Quotation
The **exact words** of a source, placed in **quotation marks** (or indented for a long quotation), followed by a **citation**.
:::

:::definition Paraphrase and summary
A **paraphrase** restates one idea **completely in your own words and sentence structure**; a **summary** gives only the **main points** of a longer text, much shorter. **Both still need a citation**, because the idea is not yours.
:::

:::definition Common knowledge
Facts that are **widely known** and found in many sources (e.g. "Astana is the capital of Kazakhstan"). They **do not need** a citation; statistics, opinions and specific findings do.
:::

:::compare Quoting, paraphrasing and summarising
| Method | How | Length compared with the original | Citation needed? |
|---|---|---|---|
| **Quotation** | The **exact words**, in **quotation marks** | The same | **Yes** — with the page if possible |
| **Paraphrase** | The idea rewritten **completely in your own words and structure** | About the same | **Yes** |
| **Summary** | The **main points**, in your own words | Much **shorter** | **Yes** |
| Common knowledge | Widely known facts | — | No |
:::

:::example Citing a source (Harvard style)
In the text: *Normalisation reduces data redundancy (Connolly and Begg, 2015).*

In the reference list: *Connolly, T. and Begg, C. (2015) Database Systems. 6th edn. Harlow: Pearson.*

A web page: *Microsoft (2026) Create a table of contents. Available at: support.microsoft.com (Accessed: 10 October 2026).*

Every citation in the text has a matching entry in the **reference list**, which is in **alphabetical order** of authors.
:::

:::steps How to paraphrase correctly
- Read the passage until you **understand** it; then **close** the source.
- Write the idea **from memory**, in your own words and your own sentence structure.
- Compare with the original: no long phrases copied; the **meaning** is unchanged.
- Put any unique phrase you kept in **quotation marks**.
- Add the **citation** (author, year).
:::

:::tip Good habits
Keep a list of every source **while you research** (author, title, date, URL, date accessed), write notes **in your own words**, mark copied text in your notes clearly, and use the word processor's **References** tools (citations, bibliography, footnotes). Check your own document with an anti-plagiarism resource **before** you submit it.
:::

:::warning Common mistakes
- Quotation marks **without** a citation, or a citation **without** quotation marks around copied words.
- Swapping a few words for synonyms and calling it a paraphrase — that is **patchwriting**.
- A citation in the text that is **missing from the reference list**, or "Source: Google".
- Citing "common knowledge" for statistics or someone's opinion.
:::

# Copyright protection rules
@lo 12.1.3.6

:::definition Copyright
The **exclusive legal right of the author** (or owner) of an original work — text, software, music, images, films, websites — to **copy, distribute, adapt, publish and perform** it, and to **allow or forbid** others to do so.
:::

:::definition Licence
**Permission from the copyright owner** to use a work under stated **conditions** (e.g. one computer, non-commercial use only, credit the author). It does **not** transfer ownership.
:::

:::definition Public domain
Works that are **no longer protected** by copyright (the term has expired) or whose owner gave up the rights. Anyone may use them freely.
:::

:::compare The main rules of copyright protection
| Rule | Explanation |
|---|---|
| **Copyright is automatic** | A work is protected **from the moment it is created** in a material form — no registration is needed; the © sign is optional but useful |
| **The work must be original** | It is the author's **own creative work**, recorded in some form (written, saved, filmed) |
| **The author owns the rights** | **Economic rights** (to earn money from copies, licences) and **moral rights** (to be named as the author, to protect the work from distortion) |
| **Protection lasts for a limited time** | In Kazakhstan and many countries: the author's **life + 70 years**; afterwards the work enters the **public domain** |
| **Permission is needed** | To copy, publish, translate, adapt or sell a work you need the **owner's permission** or a **licence** |
| **Ideas and facts are not protected** | Copyright protects the **expression** (the text, code, image), not the idea itself |
| **Limited free use is allowed** | **Quotation** for study, criticism, news or teaching is allowed **with the author's name and source** and only to a justified extent |
| **Software is protected like a literary work** | Copying, distributing or installing software without a **licence** is illegal |
| **Licences set the conditions** | E.g. **Creative Commons**; open-source licences (GPL, MIT); a commercial **EULA** |
| **Breaking copyright has consequences** | Removal of content, fines, compensation to the owner, criminal liability in serious cases |
:::

:::compare Creative Commons licence elements
| Element | Meaning |
|---|---|
| **BY** (Attribution) | You must **credit the author** |
| **NC** (NonCommercial) | Only **non-commercial** use |
| **ND** (NoDerivatives) | You may **not change** the work |
| **SA** (ShareAlike) | Changed versions must use the **same licence** |
| **CC0** | The author gives up the rights — like the **public domain** |
:::

:::callout info The law in Kazakhstan
Copyright is protected by the **Law of the Republic of Kazakhstan "On Copyright and Related Rights"** and the **Civil Code**. Computer programs and databases are protected works.
:::

:::compare Using other people's work in a school project
| You want to… | Allowed if… |
|---|---|
| Quote two sentences from a book | They are in **quotation marks** with a **reference** |
| Use a photo from a website | It has a **Creative Commons** or free licence (follow its conditions) or you have **permission** |
| Use a song in a video | It is **royalty-free / licensed**, or you have permission |
| Use code from an online tutorial | Its licence allows it, and you **credit** the author in comments |
| Use a classmate's work | **Never** as your own work |
:::

:::example Worked example — a school website
*Daniyar builds the website of the school robotics club. He wants to use (a) a photo from a news site, (b) a CC BY-NC image, (c) a quotation from an interview, (d) a JavaScript menu from GitHub under the MIT licence.*

1. **(a) News photo** — protected; no licence shown → he must **ask permission** or take his own photo.
2. **(b) CC BY-NC image** — allowed, because the club site is **non-commercial**; he must **credit the author** (BY).
3. **(c) Quotation** — allowed as **free use** if short, in quotation marks, with the **speaker and source** named.
4. **(d) MIT code** — allowed; the licence requires keeping the **copyright notice** in the code.
:::

:::warning Common mistakes
- Thinking that copyright must be **registered**, or that a work without © is free — protection is **automatic**.
- Thinking that everything on the Internet is in the **public domain**.
- Believing that crediting the author is enough to use **any** work — you also need **permission or a licence**.
- Saying that copyright protects **ideas** — it protects their **expression**.
:::

# Exam practice and summary
@lo 12.1.3.5 12.1.3.6

:::example Exam-style questions with model answers
**Q: Name two copyright protection rules. [2]**
Any two: copyright arises **automatically** when the work is created (1); copying / publishing needs the **owner's permission / licence** (1); quotations must name the **author and source**; protection lasts for the author's **life + 70 years**; ideas are not protected, only their expression.

**Q: Explain the difference between quoting and paraphrasing. [2]**
A quotation uses the **exact words** in quotation marks (1); a paraphrase restates the idea **in your own words**; both need a citation (1).

**Q: A student finds a photograph on a website and wants to use it in a project report. Describe what the student must do to use it legally. [3]**
Check the **licence / terms** of the photo (1); if it is not free (e.g. no CC licence), ask the **owner for permission** (1); follow the licence conditions and **credit / cite** the author and source (1).

**Q: Explain why copyright protects software. [2]**
Software is an **original creative work** of its authors (1); without protection it could be copied and sold freely, and the authors would lose income / control (1).

**Q: State what is meant by the public domain. [1]**
Works no longer protected by copyright / free for anyone to use (1).
:::

:::warning Common mistakes in answers
- Mixing up **plagiarism** (an ethical / academic problem: not acknowledging the source) and **copyright infringement** (a legal problem: using without permission). Both can happen at once.
- "Copyright lasts forever" — it lasts for a **limited time**.
- Answering "paraphrasing means changing some words" — the whole idea is rewritten **and** cited.
:::
